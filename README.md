# BETTERX #
### Что такое BETTER-X?
BETTER-X — это учебный веб-проект, имитирующий интерфейс и логику популярных азартных игр (crash, кейсы, колесо фортуны, слоты). Проект создан для:
- Демонстрации игровых алгоритмов и математики генераторов случайных чисел;
- Отработки веб-разработки (Canvas API, анимации, работа с localStorage);
- Развлечения пользователей без риска потери реальных средств.

### Это не азартная игра!
BETTER-X — это полностью виртуальная симуляция игровых механик. Все ставки, балансы, «выигрыши» и предметы являются вымышленными и не имеют никакой реальной денежной ценности. Никакие настоящие деньги не принимаются, не выводятся и не выплачиваются.

Все транзакции внутри платформы — это игровая имитация для развлечения и демонстрации игровых алгоритмов.
